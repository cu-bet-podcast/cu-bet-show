# 씨유벳

씨유벳은 온라인 후기와 소개 글을 읽을 때 놓치기 쉬운 출처와 맥락을 정리하는 콘텐츠입니다. 누가 작성했는지, 언제 공개했는지, 직접 확인한 내용이 어디까지인지를 나누어 살펴봅니다. 짧은 화면 캡처나 강조된 한 문장만으로 전체 상황을 판단하지 않도록 읽기 노트를 제공합니다. 씨유벳의 소개 글은 사실과 의견을 구분하는 데 초점을 맞추며, 특정 서비스의 이용 결과나 안전성을 보장하지 않습니다.

## 후기를 읽기 전에 남길 세 가지

씨유벳의 기록은 작성 주체, 게시 시점, 원문 위치에서 시작합니다. 같은 글이 여러 곳에 복사되어 있어도 서로 다른 경험이 여러 건 쌓인 것으로 세지 않습니다. 최초 게시물을 찾지 못했다면 출처 미확인으로 표시하고, 직접 경험한 이야기인지 다른 사람의 말을 옮긴 것인지 구분해 둡니다.

## 화면 한 장이 보여 주는 범위

캡처에는 그 순간 화면에 보이는 내용만 담깁니다. 앞뒤 대화나 생략된 조건까지 증명하는 자료는 아닙니다. 씨유벳 읽기 노트에는 화면에서 확인한 사실과 작성자가 덧붙인 해석을 따로 적습니다. 잘린 문장이나 날짜가 빠진 이미지라면 그 빈칸을 추측으로 채우지 않습니다.

## 기록을 다시 살펴볼 때

게시물이 수정되면 이전 메모를 지우기보다 확인 날짜와 달라진 부분을 함께 남깁니다. 표현이 바뀌었는지, 근거 자료가 추가되었는지, 원문이 사라졌는지를 적으면 나중에도 판단의 이유를 이해할 수 있습니다. 이 페이지는 개별 사건을 조사한 보고서가 아니라 그런 기록을 돕는 안내입니다.

기존 공개 연주 파일을 재사용하며, 본문의 음성 해설은 포함하지 않습니다.
